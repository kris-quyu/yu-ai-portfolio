# 个人 AI 能力网站电影化改版设计规格

日期：2026-07-28  
项目：QX / AI LAB  
站点：`yu-ai-portfolio`

## 1. 改版目标

将现有作品集升级为一条完整的能力叙事：

> 加载系统 → 认识“宇” → 看见能力成长 → 查看作品 → 理解工作流 → 探索技能 → 建立联系

网站不是传统简历，不限定具体岗位，不展示“4 年工作经验”，不提供简历下载。重点展示 AI 工具、内容创作和电商转化三者的组合能力。

## 2. 页面顺序

1. 加载界面
2. 鼠标跟随开场首页
3. 人物滚动能力成长
4. AI 视频作品
5. AI 工作流
6. 点击翻转技能
7. 联系方式

固定导航对应：`HOME / PROFILE / FILM / SYSTEM / CAPABILITIES / CONTACT`。当前区域使用荧光绿标记。

## 3. 视觉系统

### 3.1 色彩

- 暖矿物鼠尾草背景：`#E7EBDD`
- 深森林文字：`#07160F`
- 松针绿蒙版：`#123326`
- 荧光酸绿强调：`#B7FF2A`
- 灰鼠尾草辅助：`#89958A`
- 暖象牙白：`#F3F1E8`

不使用纯黑和纯白。浅色开场与深色能力页面形成电影式明暗切换，但共享松针绿、酸绿和鼠尾草色，保持统一品牌感。

### 3.2 图形语言

- 首页：轻微点阵、轨道线、节点和大面积留白。
- 深色页面：细描边、状态文字、进度线和克制的荧光强调。
- 圆角、边框和字重延续现有站点，不更换为模板化作品集风格。
- 动效服务于信息变化，不增加无意义粒子和持续闪烁。

## 4. 加载界面

加载页每次刷新出现。

### 4.1 内容

- 深森林绿全屏背景。
- 中央显示真实资源加载百分比，数字使用荧光酸绿。
- 小标题：`LOADING CREATIVE SYSTEM`
- 辅助词循环：`AI 内容 / 视频工作流 / 电商转化`
- 中央抽象圆形或柔和有机蒙版，不使用假图标或占位图。

### 4.2 加载策略

- 优先加载：首页字体、首页必要视觉、人物首帧海报、当前设备人物帧序列。
- 同时预热 AI 作品视频，但不让大视频无限阻塞进入。
- 最短展示约 1.2 秒，避免闪屏。
- 最长等待约 6 秒；关键人物资源完成后即可进入，其他视频继续后台加载。
- 单项资源失败时使用海报或静态内容降级，仍允许进入网站。

### 4.3 转场

到达 100% 后，中央图形扩大为全屏蒙版，揭示暖鼠尾草色首页。`prefers-reduced-motion` 模式改为快速淡入。

## 5. 独立开场首页

首页是正常一屏，不用滚动控制动画。向下滚动直接进入人物能力页。

### 5.1 文案

- 主标题：`HELLO, I'M YU`
- 副标题：`AI CONTENT CREATOR / HANGZHOU`
- 圆形蒙版内部：`你好，我是宇`
- 底部提示：`移动鼠标探索 · 向下滚动查看更多`

### 5.2 鼠标跟随

- 松针绿圆形带弹性缓动追随鼠标，保持轻微延迟，不紧贴光标。
- 圆形经过主标题时形成反色蒙版，圆内显示中文内容。
- 标题根据鼠标相对页面中心的位置产生 X/Y 轴倾斜。
- 最大视觉倾斜约 `20°`，在边缘位置达到上限；中心区域接近 0°。
- 倾斜使用平滑插值，避免抖动和突然翻面。
- 背景点阵、轨道线和少量节点做非常轻微的视差响应。

### 5.3 移动端

- 圆形默认缓慢自动漂移。
- 支持手指拖动圆形探索标题。
- 不依赖 hover 才能看到“你好，我是宇”。
- 降低倾斜幅度和背景视差，保证文字可读。

## 6. 第二屏：人物滚动能力成长

现有逐帧人物滚动动画整体后移到第二屏，保留滚动控制、反向滚动倒放和最终半身全景。

### 6.1 人物动作与文案同步

| 阶段 | 人物与镜头 | 英文主标题 | 中文能力 |
|---|---|---|---|
| 1 | 运镜推近头部，角色轻触眼镜 | `THINK WITH AI.` | 理解工具 |
| 2 | 运镜拉回半身全景，角色缓慢放下右手 | `SHAPE THE STORY.` | 形成内容 |
| 3 | 角色轻微转向镜头 | `BUILD THE WORKFLOW.` | 串联流程 |
| 4 | 角色保持稳定、自信的最终姿势 | `DELIVER THE RESULT.` | 服务转化 |

每阶段补充一句简短说明，分别强调：

1. 理解 ComfyUI、n8n、Codex 等 AI 工具。
2. 把产品卖点转成脚本、分镜和画面。
3. 将生成、剪辑和自动化串成稳定流程。
4. 让内容最终服务用户理解与电商转化。

### 6.2 文字转场

- 文案跟随人物动作区间切换，不固定显示同一句。
- 旧标题向上移动并淡出，新标题从下方进入并淡入。
- 中英文和阶段编号同时更新。
- 快速滚动时直接同步到正确阶段，不排队播放过时动画。
- 向上滚动时转场方向自然反转。

### 6.3 构图

- 桌面：文字左侧，人物右侧，标题允许轻度跨越人物边缘，形成海报层次。
- 移动：人物居中偏右，标题在左上安全区，并允许局部覆盖人物背景但不遮挡脸部。
- 底部持续显示滚动进度和当前阶段。

## 7. AI 视频作品

- 保留一个 AI 视频成片，不展示制作过程，不新增第二个视频案例。
- 标题沿用 `AI PRODUCT FILM`。
- 默认静音预览，点击进入沉浸式播放器。
- 播放器支持播放、暂停、音量、退出和键盘操作。
- 视频未完成加载时先显示封面；失败时保留封面与说明。

## 8. AI 工作流

- 保留 ComfyUI 工作流截图，证明能搭建和调试 AI 工作流。
- 不做教程，不解释每个节点。
- 标题沿用 `TOOLS INTO SYSTEMS.`
- 进入视口时，装饰性连线、节点和标签按顺序点亮。
- 可展示 `ComfyUI / n8n / Codex`，强调从工具到稳定输出。

## 9. 点击翻转技能

展示三张核心技能卡：

1. AI 内容与自动化
2. 视频编导与剪辑
3. 电商内容转化

### 9.1 交互

- 点击或键盘确认键翻转。
- 再次点击翻回。
- 同一时间允许多张卡片保持翻转，便于比较。
- 桌面 hover 只做轻微抬升和描边增强，不触发翻转。
- 卡片具备明确焦点状态和 `aria-pressed`/等价状态信息。

### 9.2 正反面配色

正面：

- 深森林背景
- 暖象牙文字
- 荧光酸绿编号、标签和焦点描边

背面：

- 暖矿物鼠尾草背景
- 深森林正文
- 松针绿工具标签
- 荧光酸绿用于熟练度、成长方向和关键结论
- 背景使用很淡的点阵/轨道纹理，与首页呼应

### 9.3 背面内容

采用“能力成长型”文案，不用虚假的百分比：

- 已能独立完成
- 正在持续强化
- 下一阶段目标
- 相关工具标签

## 10. 联系方式

- 标题：`LET'S BUILD SOMETHING.`
- 显示瞿先生、杭州、电话和邮箱。
- 电话可拨打，邮箱可打开邮件客户端，信息可复制。
- 不显示工作年限，不提供下载简历。
- 结束页延续深色主视觉，并用酸绿形成明确收束。

## 11. 页面级转场

- 浅色首页进入深色人物页时，导航与背景同步过渡。
- 后续各区块使用小幅上移、遮罩揭示或内容错位进入，不让所有板块使用同一种淡入。
- 所有转场都可逆，返回上一屏时状态正确。
- 避免滚动劫持；只有人物帧序列区域使用粘性滚动叙事。

## 12. 响应式与无障碍

- 验证宽度：360、390、768、1024、1440 和宽屏桌面。
- 保证 200% 页面缩放后核心内容和操作仍可用。
- 所有交互支持键盘，焦点状态可见。
- 文字与背景满足可读对比度；酸绿不用于大段正文。
- `prefers-reduced-motion`：
  - 加载页淡入；
  - 首页关闭强烈倾斜和追随，保留静态蒙版；
  - 人物页显示最终海报与四段可阅读内容；
  - 技能卡使用无 3D 的即时切换。

## 13. 前端组件与状态

新增或调整组件：

- `PortfolioLoader`：资源登记、真实进度、超时与揭示转场。
- `PointerIntro`：首页标题倾斜、圆形蒙版、移动端拖动。
- `HeroScrollSequence`：保留帧序列，增加阶段文案状态。
- `CapabilityGrid` / `CapabilityCard`：改为可访问的点击翻转。
- `Navigation`：增加 HOME，并正确映射新页面顺序。

核心状态：

- `loaderStatus`: loading / ready / degraded / exited
- `introPointer`: 目标位置与缓动后位置
- `heroStage`: 0–3，由滚动进度直接推导
- `flippedCards`: 技能卡翻转集合

不增加后端，不收集用户数据。

## 14. 性能策略

- 根据设备只加载对应的人物帧序列。
- 首帧和关键阶段帧优先，其余帧分批加载。
- 页面离开人物区后减少 Canvas 重绘。
- 大视频使用合适的 `preload`，加载页只做预热，不强制完整下载。
- 指针动画使用 `requestAnimationFrame` 和 transform，避免布局抖动。
- 首页背景装饰数量受控，移动端进一步减少。

## 15. 错误处理

- 人物帧失败：显示最终人物海报，四段能力改为正常滚动内容。
- AI 视频失败：显示封面和“视频暂时无法播放”。
- 剪贴板失败：选中联系方式并提示手动复制。
- 字体失败：使用系统无衬线回退，保持版式安全。
- JavaScript 被禁用：通过 `noscript` 提供基本能力、作品和联系方式。

## 16. 验收标准

- 每次刷新可看到真实加载界面，最慢 6 秒内可进入可用页面。
- 首页标题、圆形蒙版和中文内容按设计跟随指针，倾斜不超过约 20°。
- 手机端无需鼠标也能看到并操作蒙版效果。
- 页面顺序完整保留：首页、人物、作品、工作流、技能、联系。
- 人物四段动作与四段能力文案严格同步，反向滚动状态正确。
- 人物动画最终拉回素材可提供的半身全景。
- 技能卡点击翻转，正反面配色符合已确认方案。
- 不出现“4 年工作经验”和“下载简历”。
- `npm run test:run` 与 `npm run build` 成功。
- GitHub Pages 基础路径继续保持 `/yu-ai-portfolio/`。
- 主流桌面和移动尺寸无横向溢出、文字遮脸或不可操作控件。
