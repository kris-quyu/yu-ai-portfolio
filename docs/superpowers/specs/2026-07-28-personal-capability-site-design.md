# 个人能力交互网站设计说明

日期：2026-07-28
项目名称：QX / AI LAB

## 1. 项目目标

制作一个单页个人能力展示网站，通过强交互首屏、AI 视频成片和 AI 工作流证明，让访问者在 30 秒内理解瞿先生的核心价值：

> 连接 AI 工具、内容创作与电商业务，把复杂流程变成稳定输出。

网站不针对某一个岗位，不采用传统简历排版。重点展示三项组合能力：

1. AI 内容与自动化
2. 视频编导与剪辑
3. 电商内容转化

## 2. 明确不包含的内容

- 不展示 AI 视频的制作教程或详细制作过程。
- 不增加第二个 AI 视频案例。
- 不显示“4 年工作经验”。
- 不提供“下载简历”。
- 不设置传统工作经历、教育经历和证书长列表。
- 不设置后台、登录、表单提交或内容管理系统。

## 3. 视觉方向

采用已确认的 B 方向“AI 指挥中心”：

- 主背景：深炭黑与深墨绿色。
- 强调色：荧光绿色。
- 文字：高对比白色，标题使用粗体无衬线字体。
- 容器：细描边、圆角面板、状态标签和进度指示。
- 气质：技术感、创造力和可信度兼具，避免传统商务简历风格。
- 人物：高品质 3D 动画电影风格个人形象，不复制任何现有动画角色。

## 5. 动效规则

### 5.1 人物滚动序列

- 使用已选视频 `E:\D\7月28日(2)\7月28日(2)-1.mp4`。
- 从 8 秒视频中生成 WebP 帧序列。
- 桌面端使用 120 帧、最大 1600×900 分辨率。
- 移动端使用同一动作时间线的 96 帧、960×540 分辨率版本。
- 使用 Canvas 绘制当前帧，滚动进度映射到帧序号。
- Canvas 同时根据滚动阶段改变绘制缩放和取景位置，实现推进与拉回效果，不修改源视频。
- `0%–20%`：从 1.0 倍推进到约 1.55 倍，取景中心平滑移动到人物头部；使用动作开始段，角色轻触眼镜。
- `20%–55%`：从约 1.55 倍拉回到 1.0 倍，取景中心返回人物主体；使用放下右手的动作段。
- `55%–82%`：保持 1.0 倍取景，播放角色轻微转向镜头的动作段。
- `82%–100%`：保持最终取景和最终人物姿势，允许用户停留阅读标题与说明。
- 使用插值平滑滚动输入，避免触控滚动时跳帧。
- 首屏滚动叙事区域约为 250–300vh。
- 帧序列未加载完成前显示首帧海报和简短加载进度。
- 已确认使用当前约半身构图。1.0 倍拉回结果定义为“素材中的完整半身人物范围”，不重新生成腿部全身视频。

### 5.2 其他动效

- 标题按行淡入并轻微上移。
- 导航状态随当前区域更新。
- AI 视频卡片进入视口时缩放到完整尺寸。
- 工作流装饰节点按滚动方向依次点亮或熄灭。
- 能力卡片只使用小幅位移、描边变化和荧光绿色状态，不采用夸张 3D 翻转。
- 联系区进入时由深色切换到荧光绿色背景，形成结束信号。

### 5.3 动效限制

- 不使用无目的粒子背景。
- 不使用自动播放声音。
- 不使用持续晃动、鼠标拖尾或影响阅读的光效。
- 遵循 `prefers-reduced-motion`：减少动态效果时显示人物最终海报，取消固定和逐帧滚动。

## 6. 响应式设计

### 桌面端

- 人物在右侧，标题在左侧。
- 首屏接近满屏高度。
- AI 视频采用左右分栏。
- 工作流采用文字与截图分栏。
- 三项能力横向排列。

### 移动端

- 保留滚动控制人物动作。
- 人物调整为居中偏右，标题放在人物上方或左上方安全区。
- 使用专门的低分辨率帧序列，降低内存与下载量。
- AI 视频、工作流和能力面板改为单列。
- 能力面板由悬停改为点击展开。
- 联系电话和邮箱使用足够大的触控区域。

### 降级规则

以下情况显示静态人物海报，但其余内容仍可正常访问：

- 浏览器不支持 Canvas。
- 帧序列加载失败。
- 用户启用“减少动态效果”。
- 设备内存或网络条件不足以稳定播放。

## 7. 前端架构

建议使用：

- React
- Vite
- TypeScript
- GSAP ScrollTrigger
- CSS Modules 或集中式设计变量

组件边界：

- `Navigation`：导航和当前区域状态。
- `HeroScrollSequence`：人物帧预加载、Canvas 绘制和滚动映射。
- `FeaturedFilm`：AI 视频预览和沉浸式播放层。
- `WorkflowProof`：工作流截图和装饰节点动画。
- `CapabilityGrid`：能力面板与触屏展开状态。
- `ContactSection`：邮件、电话和复制功能。

所有文案和联系方式集中保存在一个内容配置文件中，组件不重复硬编码。

## 8. 数据与状态流

网站为纯前端静态站点：

1. 页面加载内容配置。
2. 人物首帧立即显示。
3. 后台按顺序预加载人物帧。
4. 滚动进度进入首屏叙事区域后，映射到当前帧。
5. 进入其他区域时，只激活当前区域所需的动效。
6. AI 视频仅在进入视口后加载并静音预览。

不收集访问者个人数据，不发送表单，不调用业务后端。

## 9. 异常处理

- 人物帧加载失败：显示静态最终海报。
- AI 视频加载失败：显示封面和“视频暂时无法播放”。
- 剪贴板复制失败：选中联系方式并提示用户手动复制。
- 邮件客户端不可用：联系方式文本始终可见。
- JavaScript 被禁用：基础文案、图片、联系方式和视频链接仍然可访问。

## 11. 验收标准

- 访问者在首屏能明确看到 AI、内容和工作流定位。
- 桌面端和手机端都能通过滚动控制人物动作。
- 向上滚动时人物动作可以自然倒放。
- 页面仅展示一个 AI 视频案例和一个工作流证明。
- 页面不显示工作年限，不提供简历下载。
- 所有导航、播放、关闭、邮箱、电话和复制操作可用。
- 360px、390px、768px、1440px 宽度无横向溢出。
- 慢速网络下先显示海报，不出现长时间空白。
- 减少动态效果模式下网站内容完整可用。
- Lighthouse 无严重可访问性错误。
